Modules 5, 6 & 7 · Model Benchmarking

Comparing ARIMA, Prophet, and LSTM

Chronological 80% / 20% train-test splitting preserves time order and prevents future data leakage.

Chronological Train / Test Split Never shuffle time series data randomly
Training Data — 80% (Earlier Dates)
Testing — 20% (Latest Dates)
Statistical Baseline

ARIMA (p, d, q)

AutoRegressive Integrated Moving Average models linear patterns using lagged sales (AR), differencing for stationarity (I), and past forecast errors (MA).

  • Strengths: Fast, interpretable, strong baseline for stationary univariate series.
  • Limitations: Basic ARIMA excludes external promos/holidays unless extended to SARIMAX.
Illustrative RMSE15.2
Illustrative MAPE12.5%
Recommended Main Model

Prophet

Developed by Meta, Prophet decomposes retail demand as y(t) = g(t) + s(t) + h(t) + εt capturing trend, weekly/yearly seasonality, and festival effects.

  • Strengths: Native holiday support, uncertainty intervals, and external promotion regressors.
  • Limitations: Needs sufficient history for yearly seasonality; manual regressor setup.
Illustrative RMSE11.8
Illustrative MAPE9.2%
Deep Learning

LSTM (RNN)

Long Short-Term Memory networks use Forget, Input, and Output gates over 30-day sequences to learn complex nonlinear multi-feature patterns.

  • Strengths: Captures nonlinear interactions and multivariate sequences on large datasets.
  • Limitations: Higher training complexity, hyperparameter tuning, and lower interpretability.
Illustrative RMSE10.5
Illustrative MAPE8.1%

Evaluation Metrics & Decision Criteria

RMSE — Root Mean Squared Error

RMSE = √( (1/n) Σ (yi − ŷi)² )

Measures average prediction error magnitude in unit terms, penalizing large forecast misses more heavily.

MAPE — Mean Absolute Percentage Error

MAPE = (100 / n) Σ | (yi − ŷi) / yi |

Expresses forecast error as a percentage. Note: undefined when actual sales yi = 0.
